INDEPENDENT RELIABILITY QA — CLOSED/LOST TERMINAL WORKER TAB REVOCATION — 2026-09-12
- Acceptance defect found: after Orchestration V2 had already revoked a managed worker's launch authority (for example SUPERSEDED/terminal), `closeManagedWorkerTabs()` retired the canonical Core Session only when `chrome.tabs.remove()` succeeded. If the user/Chrome had already closed the owned worker tab, the remove call failed with a missing-tab error and the safe Core one-task Session remained enabled/RUNNING. Core could later recreate/recover that Session and Send work whose V2 authority had already been revoked.
- Canonical fail-closed fix: terminal/superseded managed work now retires its safe Core Session even when the owned tab is already gone. Matching stale tab hints are cleared for safe sessions. If a Core operation is unresolved, failed tab removal does not erase its recovery evidence; successful removal may clear only the now-invalid tab hint. Core remains the sole Send scheduler/authority.
- Regression oracle: `closed managed worker tab still retires safe Core Session after orchestration authority is revoked`.
