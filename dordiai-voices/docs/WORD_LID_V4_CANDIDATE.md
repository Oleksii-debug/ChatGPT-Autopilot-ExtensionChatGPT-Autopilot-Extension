# Frozen v2 + v3 word-classifier candidate

This workflow creates an uninstalled research candidate. It does not change production routing, replace the rejected 64-label model, or establish native TTS quality. No predicted model label count is advertised before the actual run.

Inputs are immutable source artifacts: v2 training run45017654339 artifact14753180217 and v3 acquisition run45021734219 artifact14753916865. Both artifact identities, source-corpus SHA256 checksums, v2 source receipts, the exact v3 acquisition-report Git object and original45 model/partition digests are checked. The v3 converter accepts only the explicit pilot format and validates original publisher roles, reproduced pilot splits, native-family counts and locked primary-source receipts. It does not pretend v3 is a v2 corpus.

All labels are merged by normalized spelling. Publisher test overrides validation and train globally across baseline/v2/v3 labels; remaining spellings use the unchanged global spelling-hash split. Fewer than100 actual training spellings in a genuine native family excludes a class; losing any original45 learned class aborts the candidate. Original GN/HT labels gain genuine new native data rather than renamed neighbor labels. Actual trained classes and disabled outputs are reported separately.

The candidate runtime has its own format and lives under tools/vendor. It distinguishes actual Unicode native families, including MEETEI and ORIYA, from historical OTHER script labels. Native-family minima are reserved within deterministic per-class training caps. Uniform-prior character-ngram NB architecture and quantized weights remain compact and independent of voice profiles.

Temperature and per-PREDICTED-class confidence thresholds are selected solely on validation. A class must have at least200 accepted validation predictions, at least98% empirical source-membership precision and a Wilson95 lower bound at least95%. The threshold maximizing accepted validation predictions among passing grid candidates is fixed before final-test evaluation. Otherwise its threshold is null: explicit abstention, never reranking a different enabled class. Shared Arabic/Bengali/Devanagari scripts require at least two learned actual-family competitors before accepting any class from that family. Threshold search and reuse of validation do not establish population-level guarantees.

The final test is evaluated after serialized policy freeze, including per-predicted-class precision and single/multiple-reference breakdowns. Candidate and historical45 model are also tested on identical jointly unseen original45/core word/reference sets, with word and reference digests. Lower core or45 coverage cannot be hidden by pooled accuracy; all learned-but-disabled original classes remain explicit in the report. A full merged corpus, global split counts/digests, training-pair digest, family counts, calibration search, candidate model and exact report are retained for independent reconstruction.

No native_word_routing capability is enabled. Even a good isolated classifier must pass separate integrated raw marked-text router evaluation before a future capability declaration. Homographs, borrowing, source noise, untrained languages and unsupported orthographies remain limitations. Actual acceptance or installation is a later parent-reviewed decision; this workflow never installs a model.

The reused v2/legacy final-test words were previously inspected during development. They remain fixed comparison benchmarks and never enter this run's calibration; they are not described as a fresh preregistered blind benchmark. A separate report evaluates newly introduced v3-only final-test spellings absent from every baseline/v2 corpus, with its own exact word digest. It also never affects fitting decisions.
