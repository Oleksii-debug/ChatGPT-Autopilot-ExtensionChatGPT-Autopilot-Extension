dordiai-voices Єдиний голос 0.3.8

Sara 1, Elis and Bella read Ukrainian, Russian, English, Slovak, Polish, German, French, Danish, Italian and Spanish. All ten languages use one local acoustic model and the chosen speaker profile.

Press NVDA+Control+S and choose “dordiai-voices Єдиний голос”. Use the synthesizer settings ring to select the voice, rate, multiplier, pitch, timbre and volume. For numbers, choose a language or leave the setting on automatic.

The synthesizer uses document language tags when available. For untagged text it uses word frequencies and context. A word with the same spelling in several languages may need a document language tag. Character navigation uses prepared recordings. Say All starts preparing upcoming lines while the current line is being read.

At high rates, version 0.3.9 can use the verified AMD Radeon 15E7 to produce speech in parallel. Normal-rate speech and prepared spelling use the existing renderer.

Open preferences with NVDA+Ctrl+Shift+F10 or from NVDA's Tools menu. Choose enabled voices and languages, the default language, rate, multiplier, volume, pitch and timbre. Changes are saved in the current NVDA profile. Text in disabled languages uses the default language. Cancel discards unapplied changes.
