dordiai-voices 0.13.1-dev.9

Development build for testing. Real Windows/NVDA pronunciation, accessibility and audio latency acceptance is not complete. The selected development catalogue is not a list of already supported languages.

Installation

Install the main nvda-addon through NVDA and restart. Press NVDA+Control+S and select dordiai-voices. Ukrainian, English and Russian are initially enabled. Other installed languages remain opt-in.

Settings

Press NVDA+Control+Shift+F10 or use the dordiai-voices entry in NVDA Tools. Use Tab and Shift+Tab to move, Space to toggle checkboxes. Select installed languages, the default language, and a compatible voice for each language. Text and letters use the same language assignment. Keep at least one working language and voice enabled.

Automatic mode respects language tags and available language evidence. Forced mode uses the selected default language. Identically spelled words from different languages may require explicit tags or a chosen language priority.

Optional packages

Use the Packages tab to select a local ZIP package, restart NVDA, then enable the installed languages. Resource ZIPs are not separate NVDA add-ons. Disabling a checkbox does not remove files. Remove an optional package separately to reclaim disk space. The core package is not removed here.

Testing and problems

Test typing, letters, word navigation, text reading and language changes. A synthesis failure is not successful reading. Include the text example, NVDA version, selected voices/languages and NVDA log when reporting a problem. Keep your usual working synthesizer available until acceptance is complete.
