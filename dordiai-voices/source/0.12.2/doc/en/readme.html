121 languages are available. The 111 additional pronunciations use the selected voice, follow language information from NVDA and examine the script and words in untagged text. Isolated short words may have different pronunciations in different languages. Reading in a new language for the first time loads its speech engine. Prepared letter names and frequent Hebrew and Galician commands are available immediately after voice selection. Additional personal language data is discovered in D:/Синтезатор мовлення KX-47/Особисті мовні моделі. With an optional model present, “Мова тексту без позначки” in Speech settings and the settings ring chooses the language of untagged text. Each optional model has its own license.

This local NVDA synthesizer includes 53 voices. Open dordiai-voices-0.12.1.nvda-addon, install it and restart NVDA. Use NVDA+Control+S to choose dordiai-voices.

NVDA speech settings and the synthesizer settings ring let you select a voice, rate, rate multiplier from 1 to 5, volume, pitch, timbre and the language used to read numbers. You can also configure the English and Russian voice pairs.

For Slovak, Polish, German, French, Danish, Italian and Spanish, the foreign-language pronunciation setting offers native pronunciation with the selected speaker's tone or the faster shared engine. The default follows the selected voice. An unfamiliar sentence takes longer to start than a prepared recording.

0.11.7. For the seven additional languages, default and native pronunciation play prepared letter names for the selected speaker immediately. Rate, volume, pitch and timbre settings apply. Twelve Danish NVDA commands are also prepared for every speaker. Some voices have clearer Ukrainian letter names for є and с at the maximum spelling rate.

Open preferences with NVDA+Ctrl+Shift+F10 or from NVDA's Tools menu. Choose enabled voices and languages, the default language, rate, multiplier, volume, pitch and timbre. Changes are saved in the current NVDA profile. Text in disabled languages uses the default language. Cancel discards unapplied changes.
