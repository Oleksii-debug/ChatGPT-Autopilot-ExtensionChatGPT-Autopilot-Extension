# Покриття вибраного мовного каталогу

Це відтворювана перевірка реальних файлів указаного runtime. Вона не запускає синтез мовлення.

Вибрано 135 пунктів. Для 83 є реєстрація та необхідні непорожні файли. Для 52 немає зареєстрованого мовного рушія/ресурсів. Ще 0 зареєстрованих пунктів мають відсутні залежності.

З них ресурсів для повних вибраних пунктів: 83; явно позначених часткових варіантів груп: 0. Частковий варіант не закриває всю групу.

Позитивний результат інвентаризації не означає перевірену правильність вимови. Кількість підтверджених цим звітом акустичних перевірок Windows/NVDA: 0.

## Наявні типи ресурсів

- PocketTTS: нейромоделі: 2 пунктів.
- Piper: нейромоделі з перетворенням тембру: 6 пунктів.
- Holos: нейромодель: 1 пунктів.
- Спільна багатомовна нейромодель з перетворенням тембру: 21 пунктів.
- eSpeak: синтез за правилами з нейронним перетворенням тембру: 51 пунктів.
- RHVoice: статистичний синтез з перетворенням тембру: 1 пунктів.
- Спеціалізована нейромодель з перетворенням тембру: 1 пунктів.

eSpeak з перетворенням тембру не позначається як нативна нейромодель вимови. Воно змінює тембр, але не доводить природної артикуляції чи правильних назв символів.

## Географічне покриття

Мови, спільні для кількох регіонів, тут повторюються; регіональні підсумки не слід додавати для отримання кількості унікальних мов.

- Європа: вибрано 37; ресурси наявні для 35; відсутні для 2.
- Північна Америка, Центральна Америка та Кариби: вибрано 4; ресурси наявні для 4; відсутні для 0.
- Південна Америка: вибрано 8; ресурси наявні для 6; відсутні для 2.
- Азія: вибрано 54; ресурси наявні для 41; відсутні для 13.
- Африка: вибрано 39; ресурси наявні для 10; відсутні для 29.
- Австралія та Океанія: вибрано 9; ресурси наявні для 3; відсутні для 6.

## Межі висновку

- 135 пунктів є вибраним каталогом, а не 135 доведеними акустичними можливостями.
- 83 позитивних записів — наявні зареєстровані файли; вимову, запуск Windows/NVDA й затримки цей аудит не перевіряє.
- Норвезьку зіставлено з nb; існуючий nn залишається окремим необов’язковим варіантом ресурсу, а не додатковою вибраною мовою.
- Коморська і Тамазигхт — групові назви. Кабільський ресурс позначається власним кодом kab і частковим варіантом вибраної берберської групи; це не стандартна марокканська тамазигхт (zgh/tzm).
- Для групових записів на кшталт кечуа, фула чи курдської потрібна перевірка конкретного стандарту: один готовий ресурс не доводить покриття всіх різновидів.
- Мандаринську не замінено всіма китайськими мовами; філіппінську та чорногорську не підмінено іншими ресурсами через близькість назв.
- Наявні 38 записів поза вибором не збільшують виконання цільового каталогу.

Повний машинний перелік зі статусом кожного вибраного пункту: `evidence/language_coverage.json`.

Для відсутніх ресурсів потрібні справжні сумісні моделі/фонетичні правила, точні мовні ідентифікатори, ліцензійні відомості, пакет і перевірка звучання. Підміна іншою мовою або додавання назви в JSON не усуває прогалини.
