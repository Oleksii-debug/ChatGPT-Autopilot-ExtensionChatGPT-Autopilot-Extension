# dordiai-voices

Модульний локальний синтезатор для Windows і NVDA. Розробка триває; повна готовність продукту ще не підтверджена.

Поточна незмінна контрольна збірка — **0.13.1-dev.9**: 1 767 414 839 байтів для завантаження. Її виробничий код зафіксований у commit `b364060750b4fda22eb7f06b5c52085c3f4e0bfc`. Нові зміни робочої гілки не змінюють уже зібраний архів.

## Що перевірено

- Основні рушії трьох початкових мов і всі 21 додатковий рушій, для якого в тесті були контрольні фрази, дали звук у Windows.
- Справжній NVDA 2026.3.1 завантажує додаток, відкриває налаштування й обробляє клавіатуру. Виправлено доступ до готових літер за довгими шляхами.
- На тому самому архіві пройшли дев’ять випадків справжнього введення з різними розкладками, з озвученням символів і слів. Окрема перевірка справжнього зникнення ресурсу підтвердила відновлення мовлення.
- Для всіх 29 додаткових моделей MMS перевірено бітову тотожність оригінального і спільного обчислення. Зібрано 29 окремих пакетів; кожен установлено, перевірено й видалено в тесті.
- Робочий код має 748 регресійних перевірок у Linux; у цьому запуску 31 перевірку явно пропущено через відсутні додаткові залежності. Це новіший набір інструментів, а не склад початкової збірки dev.9.

Windows CI не має аудіопристрою. Перевірки звуку використовують явно позначений приймач PCM: вони підтверджують роботу справжніх моделей і програмних маршрутів, але не звучання динаміків, правильність вимови носієм мови чи фізичну затримку.

## Що залишається

У вибраному каталозі 135 пунктів. Інтегровані ресурси є для 124 повних пунктів і одного часткового; десять ще не мають інтегрованого ресурсу. Дослідні моделі не зараховуються як готова підтримка.

Залишаються підготовка відсутніх назв цифр і пунктуації, розширення перевіреної мовної класифікації, швидкодія повільних моделей, тривале змішане читання та остаточна перевірка вимови й фізичного аудіовиходу. Не всі 45 дозволених профілів сумісні з кожним акустичним рушієм.

## Де продовжувати

- `FINAL_PRODUCT_SPEC_UK.md` — погоджена кінцева ціль.
- `WORK_STATE.json` — актуальні факти й незавершені вимоги.
- `evidence/product_acceptance.json` — окремі вимоги приймання.
- `RESUME_CURRENT_UK.md` — точне продовження роботи й відомі обмеження.
- `source/0.12.2/` — робочий код; початкові архіви не змінюються.
- `PACKAGING_UK.md`, `VOICE_PACKAGES_UK.md` — збирання й додавання голосових пакетів.
- `evidence/` — збережені фактичні звіти та контрольні суми.

Поширений користувачем пакет 0.12.1 не отримано й не змінено. Окремий експеримент unified 0.3.10 збережено поза поточною розробкою. Інша програма тимчасового репозиторію залишається без змін.

## Перевірка та збирання

```text
python -m pip install -r dordiai-voices/tests/requirements.txt
python -m unittest discover -s dordiai-voices/tests -v
python dordiai-voices/tools/restore_main.py --cache LOCAL_DOWNLOAD_CACHE --discard-downloads
python dordiai-voices/tools/build_release.py
```

Великі моделі не входять у Git. Відновлення перевіряє контрольні суми вихідних ресурсів. Ядро й додаткові мовні пакети встановлюються окремо. Нові версії перевіряються за власним архівом, commit і звітами; успіх старішої версії не переноситься на них автоматично.
