# dordiai-voices — розробка модульного синтезатора NVDA

Розробку дозволено користувачем 22 листопада 2026 року, включно з автоматичними рішеннями без додаткових запитів. Поточна перевірена за складом збірка: **0.13.1-dev.6**. Ядро: 1 767 406 268 байтів для завантаження, 2 130 470 392 байтів установлених файлів. Завершення всього продукту поки не підтверджене.

Ця папка ізольована від іншої програми в тимчасово використаному репозиторії Autopilot. Її код не змінюється.

- `FINAL_PRODUCT_SPEC_UK.md` — погоджені вимоги кінцевого продукту.
- `SELECTED_LANGUAGES_UK.md`, `selected_languages.json` — вибраний каталог і порядок роботи без географічних повторів.
- `WORK_STATE.json` — фактично виконані роботи, відкриті вимоги та перевірки.
- `evidence/product_acceptance.json` — окремі незакриті вимоги приймання; наявність ресурсу не зараховується як якість мовлення.
- `source/0.12.2/` — оновлений код основного синтезатора для накладання на перевірені вихідні ресурси.
- `source/unified-0.3.10/` — збережений окремий експериментальний синтезатор; до поточної розробки не входить.
- `LANGUAGE_COVERAGE_UK.md`, `LANGUAGE_RESOURCE_GAPS_UK.md` — фактична наявність ресурсів і дослідження відсутніх моделей.
- `PACKAGING_UK.md` — відтворюване збирання ядра й додаткових мовних пакетів.
- `VOICE_PACKAGES_UK.md` — підключення підготовлених голосових даних до спільних адаптерів.
- `tests/` — регресійні перевірки мов, голосів, налаштувань, черг та пакетів.
- `AUDIT_UK.md`, `evidence/archive_inventory.json.gz` — початковий аудит незмінених архівів.

## Перевірка коду

```text
python -m pip install -r dordiai-voices/tests/requirements.txt
python -m unittest discover -s dordiai-voices/tests -v
```

Останній основний набір із 485 перевірок успішно пройшов на основному Linux-сервері та у Windows для контрольної версії dev.5. Прототипи, які зараз інтегруються, не отримують автоматично цей статус.

Ці перевірки не засвідчують правильність вимови чи фізичні затримки аудіопристрою. Для справжнього Windows-рушія та NVDA додано окремі засоби `tools/windows_engine_probe.py` і `tools/windows_nvda_probe.py`. Результати автоматичного сервера відокремлюються від прослуховування носіями мов.

## Відновлення ресурсів і збирання

```text
python dordiai-voices/tools/restore_main.py --cache LOCAL_DOWNLOAD_CACHE --discard-downloads
python dordiai-voices/tools/build_release.py
```

Великі вихідні ресурси зберігаються в `packages/0.12.2`, готові архіви — у `dist`; обидві папки не входять до Git. Відновлення перевіряє SHA-256 вихідного архіву та головного додатка й не використовує підключений обліковий запис Google Drive. Завантаження залежить від доступності початкового спільного архіву.

Для відновлення обох незмінених вихідних пакетів залишається `tools/restore.py`, а `tools/validate.py` перевіряє саме ці початкові пакети. Їхні старі кількості мов і голосів не є показниками нового випуску.

## Поточні межі

Вибрано 135 пунктів каталогу. Початкова інвентаризація переданих файлів знаходила ресурси для 83. Після додаткової інтеграції ресурси присутні для 125 пунктів: 124 повних за обраним стандартом і один явно частковий. Для десяти пунктів ресурсів ще немає. Актуальна інвентаризація — `LANGUAGE_COVERAGE_DEV2_UK.md`; її назва позначає ітерацію інвентаризації, а не номер готового випуску. Ці кількості не підтверджують правильність вимови, озвучення всіх символів чи швидкодію.

[Остання фактична перевірка Windows — запуск 44997655739](https://github.com/Oleksii-debug/ChatGPT-Autopilot-ExtensionChatGPT-Autopilot-Extension/actions/runs/44997655739) виконувалася з ядром dev.5, SHA-256 `7ffbb27a17a57cc5de377df095436985a7920fd4c22a73332e875823d200fb5d`. Окремий від NVDA рушій створив PCM трьома початковими мовами двічі, пройшов розширену перевірку 21 мовою та нову модель MMS для хауса. Ці групи частково перетинаються; решта 62 мов розширеного комплекту не запускалися через відсутність тестових фраз. Одинадцять перевірок символів пройшли перевірку структури; один дослідний випадок явно відхилено. Це не є прийманням вимови чи клавіатурного відлуння.

Справжній NVDA 2026.3.1 вибрав драйвер, показав 45 дозволених голосів і три початкові мови. Вікно налаштувань, прив’язка гарячої клавіші, Tab та зміна галочки пробілом пройшли обмежену перевірку інтерфейсу. Проте озвучення фрази не передало PCM: дочірній процес знову завершився `ImportError: marisa_trie` в українському словнику наголосів. Скидання пошуку DLL фактично виконалося, але не усунуло помилку; окремі перевірки імпорту `RecordTrie` і побудови словника поза NVDA успішні. Аварійний перехід вибрав вбудований Windows-драйвер, але його чутність не перевірена.

Точні JSON-протоколи цього запуску збережено у `evidence/windows_dev5_run_44997655739.json.gz`; SHA-256 і шляхи звітів також записані в стані проєкту.

На Windows-сервері виявлено нуль звукових виходів. Перевірка NVDA використовувала явно позначений записувач замість фізичного WavePlayer. Передавання PCM у самому NVDA, фізичний звук, повна доступність під час друку, вимова та акустичні затримки залишаються неприйнятими.

У новому голосовому каталозі залишено 45 дозволених профілів. Вісім виключених ідентичностей блокуються на межі запиту та вилучаються з комплектування. Початковий інсталятор містить три погоджені типові мови, решта встановлюються додатковими пакетами.

Раніше поширений файл 0.12.1 не був отриманий. Його не змінювали. Повна початкова папка розробки, навчальні матеріали та нативні вихідні коди до переданого архіву не входили.

Перевірене відновлення: `tools/restore_core_backup.py` збирає точний інсталятор із збережених частин; `tools/recover_core_baseline.py` перевіряє й відновлює його основні ресурси для накладання нового коду. Фактичне збирання dev.5 тільки з перевіреного ядра dev.4 і нового коду дало ідентичний SHA-256. Це відновлює ядро; відсутні в ньому додаткові мовні пакети потрібно отримувати окремо.

Поточний стан після недоступності локального середовища: RESUME_CURRENT_UK.md. Новий повний Windows-запуск dev.6 виявив додаткові збої; повна готовність залишається непідтвердженою.
