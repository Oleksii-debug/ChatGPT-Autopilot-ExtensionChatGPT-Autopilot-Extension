ChatGPT Автопілот 0.5.0 — AI SESSION TUNING

НОВЕ
- AI Manager отримав allowlisted action TUNE_SESSION.
- TUNE_SESSION вимкнений за замовчуванням і вмикається окремим checkbox у панелі AI Manager.
- Доступні лише 4 bounded timing fields:
  * minimumSendIntervalMinutes: 1-1440;
  * preSendDelaySeconds: 1-30;
  * busyCheckDelaySeconds: 1-30;
  * retryBackoffSeconds: 5-3600.
- AI Manager prompt отримує current timing values кожної Session і явний SESSION TUNING PERMISSION ENABLED/DISABLED.

БЕЗПЕКА / INVARIANTS
- TUNE_SESSION не має полів для зміни prompt, URL, tasks, runMode, retryPolicy, auth або rate-limit hold.
- Unknown/out-of-range tuning fields відкидаються parser-ом.
- SUBMITTING та AMBIGUOUS operation не можна tune.
- Зменшення minimum interval не скорочує уже встановлений nextAllowedSendAt.
- Збільшення interval може лише подовжити current gate від останнього verified send.
- Session version збільшується після реальної tuning mutation.
