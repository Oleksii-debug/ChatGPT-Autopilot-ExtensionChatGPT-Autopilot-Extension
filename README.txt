ChatGPT Autopilot Extension v0.1 — інструкція релізного пакета

СТАТУС
Це локальний Chrome Manifest V3 release candidate. Автоматичні Core, Interaction, UI та release-package тести мають пройти перед створенням цього ZIP.
HUMAN_TESTED=false до фактичної перевірки у Chrome.
NVDA_VERIFIED=false до фактичної перевірки Windows 11 + Chrome + NVDA.

ВСТАНОВЛЕННЯ У CHROME З КЛАВІАТУРИ
1. Розпакуйте ChatGPT-Autopilot-Extension-v0.1.zip у постійну папку. Не відкривайте розширення безпосередньо з перегляду ZIP.
2. У Chrome натисніть Ctrl+L.
3. Введіть chrome://extensions і натисніть Enter.
4. Клавішею Tab знайдіть «Режим розробника» / Developer mode. Якщо він вимкнений, натисніть Пробіл.
5. Клавішею Tab знайдіть «Завантажити розпаковане розширення» / Load unpacked і натисніть Enter.
6. У вікні вибору папки виберіть папку ChatGPT-Autopilot-Extension-v0.1, у якій безпосередньо лежить manifest.json.
7. Активуйте «Вибрати папку» / Select Folder.
8. Поверніться на chrome://extensions і перевірте, що встановлено ChatGPT Autopilot Extension версії 0.1.0 та Chrome не повідомляє про помилку розширення.
9. Відкрийте «Докладніше» / Details для розширення, потім «Параметри розширення» / Extension options. Також панель налаштувань відкривається через кнопку розширення на панелі Chrome.

ЩО Є У ПАКЕТІ
- manifest.json — опис Chrome-розширення.
- src/ — робочі файли розширення.
- src/config/portable-profile-template.json — чистий шаблон JSON для масового налаштування сеансів і завдань.
- README.txt — ця інструкція.

ПЕРЕНОСНІ НАЛАШТУВАННЯ JSON
Розширення можна залишати встановленим. У його параметрах можна завантажити порожній JSON-шаблон, заповнити його окремо або за допомогою AI та імпортувати назад.
Підтримується до 5 сеансів у файлі та до 50 завдань у кожному сеансі.
Імпорт без запуску залишає імпортовані сеанси зупиненими.
Автоматичний запуск відбувається лише тоді, коли файл його запитує і користувач окремо активує дію «Імпортувати й запустити запитані сеанси».
Імпорт не повинен перезаписувати активний або незавершений сеанс і не повинен створювати конфлікт володіння одним ChatGPT URL між активними сеансами.

ОНОВЛЕННЯ ЦЬОГО РОЗПАКОВАНОГО РЕЛІЗУ
1. Збережіть тільки одну канонічну папку ChatGPT-Autopilot-Extension-v0.1.
2. Повністю замініть її вміст файлами новішого release candidate; не накладайте нові src-файли поверх старих.
3. Відкрийте chrome://extensions.
4. Знайдіть ChatGPT Autopilot Extension і активуйте «Перезавантажити» / Reload.
5. Перевірте версію 0.1.0, відсутність помилки Chrome та відкриття параметрів розширення.

БЕЗПЕКА
- Розширення працює лише з https://chatgpt.com/*.
- У пакеті не повинно бути cookies, профілю Chrome, паролів, токенів, OAuth-файлів, приватних промптів або приватних ChatGPT URL.
- Немає обходу CAPTCHA, обмежень акаунта, підтверджень платежів або rate limit.
- Невизначений результат відправлення не вважається успішним і не дозволяє сліпе повторне відправлення.
- BUSY, помилка, невідомий стан інтерфейсу або rate limit не зараховуються як підтверджене відправлення.

ПЕРША ЛЮДСЬКА ПЕРЕВІРКА
Після встановлення спочатку створіть один тестовий сеанс з одним ChatGPT URL і безпечним тестовим промптом. Перевірте Start, Pause, Resume, Stop, фактичне вставлення, затримку перед Send, підтвердження відправлення, журнал і відновлення після перезапуску Chrome. Лише після цього переходьте до великої кількості завдань.
