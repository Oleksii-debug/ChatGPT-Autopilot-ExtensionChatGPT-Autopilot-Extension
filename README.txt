Основна зміна: введення тексту й натискання кнопки виконує сам Chrome
через Input.insertText та Input.dispatchMouseEvent. Основний шлях
розширення більше не покладається на JavaScript element.click().

Для цього у manifest.json додано дозвіл debugger. Chrome може попросити
підтвердити новий дозвіл і показувати службову панель під час взаємодії.
Код використовує цей доступ лише для введення та натискання у вкладці
завдання. Cookies, токени й мережеві відповіді не читаються.

Збережено ваші сеанси, промпти, формат даних і налаштування.
Chess-profile.json — незмінений профіль із вашого початкового архіву.

Усунено втрату підтвердження надсилання, подвійний підрахунок вкладених
елементів повідомлень і нескінченне відновлення без пояснення причини.
Дубльовані команди не запускають повторне натискання. Для старого
невизначеного стану в панелі є доступні з клавіатури дії відновлення.

у Chromium на контрольних сторінках. Живий сеанс вашого ChatGPT і NVDA
дистанційно не перевірені. Деталі перевірки містяться у QA-0.1.6.txt.
