                  Оркестрація
                  
      
                  Кожен оркестр має власні налаштування, runtime і керування. Пауза або аварійний стоп вибраного оркестру не зупиняє інші.
                  
      
                  
        
        
        
      
                  

      
                  
        
        
        
        
        
                  
          
          
          
          
          
          
        
                  
        
                  Запуск без очікування watchdog. «Запустити оркестр» одразу починає перший Coordinator-cycle. Фізичний Send відбувається після налаштованої Coordinator pre-send затримки.
                  
        
                  Безпечна локальна пауза. Пауза стосується лише вибраного оркестру: стан зберігається, налаштування можна змінити й зберегти, а інші оркестри продовжують працювати. «Продовжити оркестр» одразу запускає recovery/reconciliation, не чекаючи watchdog.
                  

        
                  
          Завантажити JSON оркестру
          
                  Працює навіть якщо оркестрів ще немає. Валідний файл створює новий оркестр автоматично. Імпорт ніколи не запускає оркестр самостійно.
                  
          
          
          
                  Файл не вибрано.
                  
          
        
                  

        
                  
          Стандартна ієрархія Director → Managers → Workers
          
                  Створює детерміновану безперервну Level-1 ієрархію до першого запуску. Після повного Director → Managers → Workers → reconciliation циклу автоматично починається наступний раунд, доки оркестр не призупинено або не зупинено. Один рядок нижче — один Manager: спочатку короткий ID, потім вертикальна риска і його область відповідальності. Workers отримують фіксовані слоти та не повинні вигадувати роботу, якщо в їхній області немає вільного завдання.
                  
          
          
          
          
          
          
          
                  Один рядок — один напрям: ID напряму з поля Managers вище | посилання Google Drive/Docs або file ID. Наприклад: runtime | FILE_ID. Файл повинен містити тільки одне ціле число від 0 до кількості Workers цього Manager. Drive не може змінити ієрархію або вибрати чужі слоти.
                  
          
          
          
                  Level 3: один рядок — Manager ID | exact Drive folder. Усередині Autopilot читає тільки generation-NNNNNN з READY і валідними dispatch JSON для безпосередніх Workers. Один Manager не може одночасно мати scalar-файл і dispatch-папку.
                  
          
          
          
          
                  Стан авторизації Drive ще не перевірено.
                  
          
          
          
          
                  Ієрархію ще не створено цим шаблоном.
                  
        
                  

        
                  Оркестри ще не створені. Створіть новий оркестр або завантажте JSON-файл.
                  
      
                  

      
                  
      
                  Налаштування вибраного оркестру. Якщо треба змінити identity або критичні параметри під час роботи, спочатку натисніть «Призупинити оркестр», внесіть зміни, збережіть і натисніть «Продовжити оркестр».

          Цикли в одному чаті
          
          
          
          
                  Послідовність промптів

Надісланий промпт або просто завершена відповідь не вважаються виконанням.

                      Вартість невідома
                        
      
                        Списки читаються зі збережених маршрутів Core. Віддалена модель без підтвердженої вартості належить до «Вартість невідома» й не запускається, доки не підтверджено безкоштовність або не задано ціну платної моделі.
                        
      
                        Необовʼязково. Якщо додано хоча б один маршрут, ролі planner, coder, fast-worker, verifier, critic і vision обираються з цього пулу. Порядок карток є порядком переваги. API keys тут не вводяться: OpenAI-compatible маршрут посилається лише на endpoint ID локального Gateway.
                        
      
                        
      
      
      
      
                        Для Містраль ключ налаштовується локальним скриптом «НАЛАШТУВАТИ MISTRAL API.ps1» у папці companion/ai-gateway. Він зберігається захищено у Windows; у цю форму ключ не вставляйте. Після запуску Gateway натисніть «Отримати моделі цього постачальника» у маршруті Містраль.
                        
      
                        Для OpenRouter використайте «НАЛАШТУВАТИ OPENROUTER API.ps1» у тій самій папці. Ключ зберігається локально через Windows DPAPI. Після запуску Gateway отримайте каталог моделей у маршруті OpenRouter. Новий маршрут вимкнений і має невідому вартість, доки ви не налаштуєте його явно.
