ChatGPT Автопілот 0.9.17 — VISUAL DRAG/TYPE + PER-AGENT AI ROUTING

FROZEN CHANGELOG — 2026-09-14

- Browser Agent vision/computer-use розширено з click_at до drag_at і type_at для visible UI без usable DOM/ARIA ref.
- drag_at є screenshot-turn-only, viewport-bounded і під default CONSEQUENTIAL завжди проходить owner approval; source і destination fingerprint перевіряються до approval execution і повторно після chrome.debugger.attach перед native input.
- Native drag використовує CDP Input.dispatchMouseEvent з коректним held-button contract: mouseMoved button=none + buttons=1; durationMs реально розподіляє рух у часі, а не лише змінює кількість миттєвих events.
- type_at працює через native coordinate focus + Input.insertText; password/file targets fail-closed як sensitive. Visual-only editor target потребує approval за замовчуванням.
- click_at/type_at/drag_at повторно перевіряють live target після debugger attach, щоб debugger-infobar/viewport shift не створив stale-coordinate click/type/drag.
- Per-Agent AI policy може успадкувати глобальний AI Router або окремо вибрати primary / strong / hybrid-auto / hybrid-rules та primary/strong provider/model.
- Per-Agent routing runtime ізольований: job counters/strong history не переписують profile-wide AI Router runtime.
- CREATE Browser Agent тепер реально зберігає AI override fields; explicit provider override без explicit model відхиляється fail-closed.
- Options Agent policy отримала keyboard/NVDA-readable controls для per-Agent AI routing/provider/model; prompt-first composer лишається основним UX.
- Real Chromium generic Agent smoke тепер перевіряє visual canvas click, coordinate drag-and-drop і coordinate editor typing.
- Ordinary Session cadence/recovery, Scenario Work і Orchestration V2 semantics не змінені.
