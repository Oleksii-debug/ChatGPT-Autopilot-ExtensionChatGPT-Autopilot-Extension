ПОЛІТИКА КОНФІДЕНЦІЙНОСТІ — ЧЕРНЕТКА ДЛЯ CHATGPT АВТОПІЛОТ

Це чернетка для майбутньої публічної сторінки. Перед публікацією треба звірити її з фактичною production-архітектурою та розмістити за стабільним HTTPS URL.

ChatGPT Автопілот зберігає конфігурацію та робочий стан локально у Chrome. Розширення взаємодіє з chatgpt.com від імені користувача для виконання налаштованих користувачем сеансів та оркестрацій. За ввімкненої GitHub orchestration функції розширення може читати контрольні дані через api.github.com. За ввімкнених локальних AI-функцій розширення може звертатися до localhost/127.0.0.1.

Розширення не повинно продавати персональні дані, використовувати їх для реклами чи приховано передавати стороннім сервісам. Будь-який майбутній license/entitlement server або платіжна інтеграція мають бути окремо описані тут до їх увімкнення у production.

Користувач повинен мати можливість вимкнути або видалити розширення стандартними засобами Chrome. Локальний стан розширення видаляється відповідно до поведінки Chrome storage при видаленні розширення.
