CHATGPT АВТОПІЛОТ — CHROME WEB STORE LISTING DRAFT

Назва:
ChatGPT Автопілот

Короткий опис:
Керує ChatGPT-сеансами та multi-agent оркестрацією з відновленням, GitHub control і локальними лімітами.

Single purpose:
Надійно автоматизувати керовані ChatGPT-сеанси та оркестри в браузері з локальними лімітами, відновленням і контрольованою взаємодією з GitHub.

Permission justifications:
- storage: durable configuration, task/session/orchestra state and recovery checkpoints.
- unlimitedStorage: large user-authored prompt profiles and bounded durable orchestration history may exceed the default local quota.
- alarms: durable wake-ups, retries, watchdog reconciliation and coordinator/worker scheduling.
- tabs: owned ChatGPT tab discovery, readiness checks, reuse/close and exact conversation ownership verification.
- scripting: isolated-world target verification immediately before verified native input.
- debugger: CDP Input commands are used only after semantic target proof to perform browser-native text insertion/click submission; attach is temporary and detached after the operation.
- https://chatgpt.com/*: the core automation target.
- https://api.github.com/*: read-only orchestration control/status retrieval.
- localhost/127.0.0.1: optional local AI gateway/model integrations.

Remote code declaration:
No remotely hosted JavaScript/WASM is loaded or evaluated by extension pages. Remote responses are treated as data/control state and validated against local schemas. The documented chrome.debugger API is used for native browser input only.

Data handling note:
The extension processes user-authored prompts, ChatGPT conversation state and configuration required to perform its requested function. A public privacy policy URL and the final Chrome Web Store Privacy-tab declarations must match the actual release behavior before publication.
